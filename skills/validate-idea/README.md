# validate-idea

判断一个项目想法值不值得继续做。

Evaluate whether a project idea is worth building.

---

## 这个 skill 解决什么问题？

很多项目不是做不出来，而是不值得做。

这个 skill 用来在正式开发前判断：

- 用户痛点是否真实
- 用户是否可能付费
- 竞争是否过强
- MVP 是否能快速做出来
- 是否适合个人开发者低成本试错

---

## 适合什么时候用？

当你有一个新想法时，先不要写代码。

先用这个 skill 评估一遍。
