# cut-mvp

强制缩小 MVP 范围。

Force-reduce project scope to the smallest shippable MVP.

---

## 这个 skill 解决什么问题？

很多独立开发项目死于：

- 功能越来越多
- 一直重构
- 很久不发布
- 想一次做完整产品

这个 skill 的目标：

不是让产品更完整。

而是：

让产品更快上线。

---

## 核心原则

- 能删就删
- 能手工就手工
- 能假装自动化就不要真自动化
- 先验证用户需求
- 先拿到第一个用户

---

## 输入内容

```text
Project:
Current feature list:
Target users:
Core value:
Available development time:
```

---

## 输出结果

```text
Must Remove:
Do Not Build Yet:
Core MVP:
24-Hour Version:
Fake Backend Ideas:
Manual Workflow Options:
Launch Requirement:
```
