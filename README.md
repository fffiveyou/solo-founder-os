# Solo Founder OS

一个给 AI 独立开发者使用的工作流仓库。

A workflow repository for AI-powered solo founders and indie hackers.

---

# 为什么做这个项目？

Why this project exists?

很多独立开发者的问题不是不会开发。

而是：

- 想法太多
- 项目越做越大
- 很久不发布
- 没有真实用户
- 没有变现
- 一直在重复开新坑

这个仓库的目标，
是把“AI 创业流程”尽量标准化。

This repository tries to standardize the workflow of AI-native solo building.

---
